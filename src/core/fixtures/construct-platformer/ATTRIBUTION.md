# Real Construct project fixture

`project.c3proj` and the associated project files are the downloadable
`platformer-abstraction.c3p` attached to Kyatric's Construct tutorial, [How to
make a platformer game](https://www.construct.net/en/tutorials/platformer-game-2329).
The tutorial page licenses its content under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The tutorial identifies its game art as Kenney's Abstract Platformer pack, licensed
CC0. The archive was extracted to this folder-project layout without editing its
project content; the original archive is available from the tutorial page.

Attribution: Kyatric, “How to make a platformer game,” Construct.net, CC BY 4.0.
